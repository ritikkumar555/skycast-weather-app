# Weather App

A responsive weather app built with vanilla HTML, CSS and JavaScript. Search any city or use your current location. The page background changes with the weather and time of day.

## Features
- Search by city or by geolocation
- Temperature, feels-like, wind, humidity and pressure
- Sky theme changes with conditions (clear, clouds, rain, thunderstorm, snow, mist) and day/night
- Clear error and loading states
- Remembers your last search
- Works on phones, tablets and desktops

## Run locally
1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api).
2. Copy `config.example.js` to `config.js` and paste your key in.
3. Open `index.html` in a browser.

## Tech
HTML, CSS, JavaScript (Fetch API, Geolocation API), OpenWeatherMap API.
